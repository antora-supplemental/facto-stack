This is the **Facto stack** demo: lean https://antora-supplemental.github.io/valentus-theme/[Valentus theme^] chrome composed with the extensions that belong in Facto — not in Valentus core.

[NOTE]
====
Want theme-only chrome (typography, layout, dark mode, search omnibox)?
See the https://antora-supplemental.github.io/valentus-theme/[Valentus theme demo^].
This stack demo proves the compose path on top of that lean UI.
====

== What this demo composes

[cols="2,3"]
|===
| Piece | Role here

| **Valentus** (`v2` UI bundle)
| Lean doc-site chrome only

| `@antora-supplemental/mermaid-client`
| Mermaid stays **source-in-HTML**; CDN runtime + light/dark re-theme (not Kroki bake)

| `@antora-supplemental/diagram-lightbox`
| Zoom / pan / lightbox for baked figures and client Mermaid hosts

| **SoftNav** (chassis `soft-nav`)
| Same-origin soft navigation between pages in this component

| `asciidoctor-kroki` (optional)
| PlantUML (and other non-Mermaid) bake when needed — Mermaid stays client

| Lunr + search chat + build-stack
| Search, metadata lead, footer attribution (Facto defaults)

| `@antora-supplemental/site-nav-tree` (`filter: true`)
| Sticky label filter above the left nav (local DOM match, not Lunr)

| `@antora-supplemental/soft-nav-page-toc`
| Rebuilds the aside page TOC after SoftNav article swaps
|===

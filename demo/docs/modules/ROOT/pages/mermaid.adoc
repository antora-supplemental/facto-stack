= Client Mermaid
:description: Mermaid rendered in the browser via mermaid-client (not Kroki bake).
:navtitle: Client Mermaid

Facto defaults can bake Mermaid through Kroki.
This demo proves the **client** path: `@antora-supplemental/mermaid-client` keeps the source in the HTML and loads a pinned CDN Mermaid runtime so light/dark can re-theme without rebuilding SVGs.

[NOTE]
====
Valentus core does **not** ship mermaid-client.
Theme-only sites stay lean; stack adopters require the package (as this playbook does).
====

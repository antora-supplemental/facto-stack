= Brand assets

[cols="1,2"]
|===
| `facto-logotype.svg` | *Source of truth.* Outlined letters (no font needed), cut into bands by the `#bands` pattern mask. Written as the dark variant (charcoal tile, white letters).
| `facto-logotype-dark.png` | 1600 px export of `facto-logotype.svg`. Do not edit by hand.
| `facto-logotype-light.png` | 1600 px export of `facto-logotype.svg` with tile and letter colors swapped (white tile, charcoal letters). Do not edit by hand.
|===

Palette: charcoal `#111111`, orange `#FF5F00`, white `#FFFFFF`.

== Regenerate the PNGs

Needs Inkscape 1.x (`inkscape` on PATH, or set `INKSCAPE` to its path).

[source,shell]
----
node scripts/export-logotype.mjs
# per variant: inkscape <svg> --export-type=png --export-width=1600 --export-filename=assets/brand/facto-logotype-<dark|light>.png
# --thumb also writes build/facto-logotype-<dark|light>-320.png for a thumbnail check
----

== Change the bands

[source,shell]
----
node scripts/export-logotype.mjs --bars 6 --gap 16
----

`--bars` (white bars cut from the letters, default 7) and `--gap` (px, default 14) rewrite the `#bands` pattern, `#band-bar` and `#base-bar` in the SVG, record the values in `data-bars` / `data-gap`, then export. By hand: the pattern `height` is bar + gap and `#band-bar` `height` is the bar.
